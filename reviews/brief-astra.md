# レビュー依頼: Suminuri v0.2(手動で四角を描いて塗るアプリ)

あなたは厳しいシニアエンジニア兼セキュリティ・UX レビュアーです。このリポジトリ(/home/admister/dev/Suminuri)は、ブラウザだけで動く「隠したい所を四角で囲んで黒く塗る」アプリです。自動検出はしません(人が決める)。PDF と画像(PNG/JPEG)に対応。React + Vite + pdf.js + pdf-lib。

**ソースコードは一切変更しないこと。** 書いてよいのは `reviews/astra-review.md` だけ。`npm run build`、`npm run preview -- --port 4181` と `CHROMIUM=$(ls -d ~/.cache/ms-playwright/chromium-*/chrome-linux64/chrome | tail -1) node tests/e2e.mjs http://127.0.0.1:4181/` は実行してよい(終わったらサーバーを止める)。テスト用の PDF/画像は自分で作ってよい(test-results/ の下に置く、架空の内容のみ)。

## 見てほしいこと(重要な順)
1. **消したはずの情報が残らないか**: 保存した PDF に文字層・注釈・フォーム・添付・メタデータ・しおり・XMP が残る経路はないか。四角の端の画素が残らないか(座標の丸め、ページ回転、CropBox/MediaBox のずれ、ユーザー単位 UserUnit、ズーム中の座標変換)。画像の EXIF・向き・ICC・PNG の tEXt 等。保存後の自己確認(verifyPdf / 画像の確認)は本当に意味のある確認になっているか、すり抜ける場合はないか。
2. **赤い文字(消える文字の表示)の正しさ**: 文字ごとの位置の推定(縦書き、回転したページ、斜めの文字、合字、半角カナ、絵文字、サロゲートペア)。四角に入っているのに赤くならない/入っていないのに赤くなるケース。
3. **壊れ方**: パスワード付き PDF、壊れた PDF、巨大なページ・大量ページ、CMYK JPEG、透過 PNG、非常に大きい画像、メモリ。エラー時に利用者に分かる表示になっているか。
4. **操作性(とてもシンプルで直感的であることが最重要)**: 初めての人が説明なしで使えるか。ドラッグ・移動・リサイズ・削除・元に戻す・仕上がり表示・保存の流れで迷う所、誤操作しやすい所。キーボード、タッチ操作、スマホ幅、ダークモード、アクセシビリティ。
5. **セキュリティ・プライバシー**: CSP、外部通信ゼロ、pdf.js の設定(isEvalSupported など)、ワーカー、依存のライセンス(GPL/AGPL がないか)。
6. **コード品質**: React の状態管理、再描画・メモリリーク(ImageBitmap、canvas、pdf.js のページ)、型、テストの不足。

## 書き方
`reviews/astra-review.md` に日本語で:
- 冒頭に総評3行。
- 指摘を **重大度順**(重大=情報が残る/壊れる、中=誤操作・使いにくさ、軽=細部)に。各指摘は「どこ(ファイル:行)」「何が起きるか(再現手順)」「直し方の提案」。実際に試して確認したものは「確認済み」と書く。推測は推測と書く。
- 最後に「すぐ直すべき上位5件」。
